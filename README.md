An advanced Python analytics engine designed to evaluate corporate financial health, execute DuPont framework performance decomposition, and perform statistical anomaly detection on operational financial data.

---

##  Project Motivation & Objective
Modern business intelligence requires bridging traditional accounting frameworks (like the DuPont analysis) with quantitative data science techniques (such as z-score anomaly detection). This project demonstrates the ability to programmatically analyze company financials, identify performance drivers, and flag irregular expenses or revenue anomalies.

---

##  Tech Stack
* **Language:** Python (Standard library statistics, math, and logging modules)
* **Core Concepts:** DuPont analysis (ROE decomposition), liquidity ratios, statistical standard deviation, z-score anomaly detection
